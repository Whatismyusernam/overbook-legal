# 오버북 약관 페이지

토스 미니앱 **오버북 : 책을 기록하다**(`digibookshelf`)의 약관 페이지예요.
앱인토스 콘솔의 약관 등록 칸에 넣을 주소를 여기서 만들어요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 두 문서로 가는 안내 페이지 |
| `terms.html` | 서비스 이용약관 |
| `privacy.html` | 개인정보 처리방침 |

## 문구를 고치고 싶을 때

1. 위 HTML 파일을 열어 글자를 고쳐요.
2. 고친 내용을 저장하고 GitHub에 올리면(commit → push), 1~2분 뒤 웹페이지에 반영돼요.
3. 내용을 크게 바꿨다면 문서 맨 위의 **최종 개정일**과 맨 아래 **부칙**의 날짜도 같이 고쳐 주세요.

## 앱이 바뀌면 함께 고쳐야 하는 것

`privacy.html`은 앱이 실제로 다루는 정보를 그대로 적어 둔 문서예요.
아래와 같은 변화가 생기면 처리방침도 반드시 함께 고쳐야 해요.

- 토스 로그인을 도입할 때 (실명·연락처를 받게 되므로 수집 항목이 크게 늘어나요)
- 인앱결제·토스페이를 붙일 때 (결제 정보 항목이 생겨요)
- 새로운 외부 서비스를 연동할 때 (처리위탁 표에 한 줄 추가)
- 광고를 실제로 붙일 때 (광고 사업자 이름을 정확히 적어 주세요)
- 수집하는 기기 권한이 늘어날 때

## 관련

- 앱 소스: `~/digibookshelf` (별도 저장소)
- 이 문서들은 표준 양식을 바탕으로 만든 **초안**이에요. 법률 자문이 아니에요.
